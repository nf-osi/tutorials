# AI Co-Scientist Workshop Outline
**Format:** Virtual Workshop  
**Duration:** 90 minutes

## Opening Session (15 minutes)

### Welcome and Setup (5 minutes)
- Welcome message and facilitator introductions
- Virtual format logistics (muting, chat, screen sharing)
- Technical support contact

### Learning Objectives (4 minutes)
- Present key workshop learning objectives
- Set expectations for remainder of workshop

### Pre-Survey Insights (6 minutes)
- **Participant Demographics**: Role distribution, NF-OSI funder representation
- **Current AI Tool Landscape**: Familiarity levels, most used tools, experience distribution
- **Sentiment and Expectations**: General AI sentiment, topics of interest, knowledge gaps

*"Understanding who's in the room helps us tailor our discussion"*

## Core Content (65 minutes)

### AI Co-Scientist Overview (10 minutes)
- Specialized biomedical vs. general AI tools
- Current capabilities and limitations
- Community-driven agentic co-scientist education and evaluation
- Live poll: Current research workflow challenges

### Biomni Platform and Synapse Integration Demos (50 minutes)

**Demo 1: Biomni + Synapse Data Integration (15 min)**
- How Biomni searches and utilizes data within Synapse to answer questions
- Live demonstration of data discovery and analysis workflow
- Q&A via chat (5 min)

*Internal Note: Cover what domains Biomni may be suited for, since AI co-scientists have different strengths and weaknesses. Biomni excels in certain research areas but may have limitations in others - be transparent about this scope.*

*Internal Note: Explain that results can be stochastic in terms of the analysis path the AI agent goes down, unless the prompt is very specific. The same query may lead to different analytical approaches or focus areas - this is important for participants to understand for reproducibility and expectation setting.*

**Demo 2 OR 3: Conditional Based on Dataset Volunteer**

**Option A - Demo 2: Targeted Analysis with Biomni (15 min)**
- Using Biomni for more targeted analysis prompts
- Focused AI-assisted research query examples
- Community impact discussion (5 min)
- *Used if no suitable volunteer dataset is available*

*Internal Note: We are demoing the open-source version of Biomni. The web app should NOT be used for controlled access data because there can be potentially shared storage/cache. Be clear about this distinction and data security implications.*

**Option B - Demo 3: Community Dataset Analysis (20 min)** *[Priority if volunteer available]*
- **Pre-vetted participant dataset** (volunteer from confirmed registrants)
- Live analysis through Biomni platform using volunteer's data
- Real-time community evaluation and feedback
- Discussion of findings and methodology
- *This replaces Demo 2 when available - more engaging with community volunteer*
- *Note: Dataset will be pre-screened for appropriateness, accessibility, and regulatory compliance*

*Internal Note: Some sensitive data cannot be used/processed with commercial AI providers, which limits actual use and what we can demo. Be transparent about these limitations when discussing real-world implementation. This affects both our demo capabilities and participants' future use cases.*

**Additional Discussion Time (15 min)**
- **Community feedback on Biomni vs. other AI co-scientist platforms**
- **Future development priorities and desired features**
- **Comparative assessment**: How does Biomni stack up against other tools participants have used?
- **Roadmap input**: What capabilities would make the biggest impact for your research?
- Extended Q&A and community interaction

*Internal Note: This discussion is especially valuable for understanding what new developments the community wants, and their take on Biomni as well as other AI co-scientists after seeing how things work. We put effort into the Biomni integration as our first foray, but it's unlikely to be the last -- other workshops might cover other options and better ways of working.*

### Wrap-up Discussion (5 minutes)
- **Key takeaways from community feedback and comparative discussion**
- **Next steps**: Future workshop topics and platform coverage based on community input
- Value of collaborative AI-assisted research and data sharing
- Thank participants for development insights and future workshop planning input

## Closing Session (10 minutes)

### Practical Implementation (5 minutes)
- Key takeaways for getting started
- Critical assessment tips for AI outputs
- Next steps for tool adoption

### Wrap-Up (5 minutes)
- Learning objectives review
- Post-survey launch and importance
- **Individual consultation offer**: Participants can email nfosi@sagebionetworks.org, mention the workshop, and we can arrange follow-up consultation time
- Thank you and final Q&A

*Internal Note: The consultation offer provides multiple benefits: quality leads for potential collaborators or power users, detailed feedback from motivated participants in 1:1 settings, use case discovery for future workshop planning, and relationship building with the most engaged community members. This personal touch can significantly extend the workshop's impact beyond the 90-minute session.*

## Virtual Format Elements
- **Engagement**: Live polls, chat Q&A, interactive demos
- **Materials**: Pre-survey slides, Biomni demo access, post-survey link
- **Accessibility**: Captions, recording (with consent), multiple question formats

## Technical Setup
- **Participant Requirements**: Stable internet, web browser, audio capability
- **Demo Format**: Facilitator screen sharing - participants observe and interact via chat
- **No Individual Setup**: Participants do not need to install or configure Biomni themselves
- **Facilitator Requirements**: Pre-configured Biomni environment, backup datasets, stable connection
